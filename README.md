## 🚀 What is Bitzy?

Bitzy is designed to help developers understand and work confidently with their existing projects.

Explore your codebase, understand unfamiliar files, investigate errors and discover potential maintainability issues without constantly switching between tools.

## ✨ Features

### 01. Project Overview

Get a clear picture of your workspace.

- Scan your project.
- Explore files and folders.
- Identify programming languages.
- Discover dependencies and technologies.
- View project statistics.

<img src="media/Bitzy Code Assistant in VS Code.png" width="100%" alt="Bitzy Project Overview">

---

### 02. Project Architecture

Visualize how your project is structured and connected.

- Explore source files visually.
- Inspect file relationships.
- Understand module dependencies.
- Explore architecture and dependency-flow views.
- Search files and modules.

<img src="media/Bitzy Project Architecture Map.png" width="100%" alt="Bitzy Project Architecture">

---

### 03. Understand My Code

Make unfamiliar code easier to understand.

- Explain selected code or active files.
- Understand functions and programming logic.
- Explore dependencies and code structure.
- Get beginner-friendly explanations.
- Understand how different parts of your code work.

<img src="media/Bitzy Code Understanding in VS Code.png" width="100%" alt="Bitzy Understand My Code">

---

### 04. Codebase X-Ray

Discover potential code-quality and maintainability issues.

- Identify oversized source files.
- Find TODO, FIXME and HACK markers.
- Detect suspicious hardcoded credential patterns.
- Review available VS Code diagnostics.
- View heuristic maintainability insights.

<img src="media/Bitzy Codebase X-Ray Dashboard.png" width="100%" alt="Bitzy Codebase X-Ray">

*The maintainability score is heuristic and is not a security certification or guarantee of software quality.*

### 05. Debugging Coach

Understand coding issues and investigate possible solutions.

- Review available VS Code diagnostics.
- Investigate potential error causes.
- Understand evidence behind detected issues.
- Explore suggested fixes.
- Learn why issues happen.

## ⚡ Getting Started

### Installation

1. Open Visual Studio Code.
2. Open Extensions using `Cmd + Shift + X` or `Ctrl + Shift + X`.
3. Search for **Bitzy**.
4. Select the extension published by **AaryanPandey**.
5. Click Install.

### How to use

1. Open an existing project folder in VS Code.
2. Click the Bitzy icon in the Activity Bar.
3. Select **Scan My Project**.
4. Explore your project architecture.
5. Use **Understand My Code** to explain code.
6. Run **Codebase X-Ray** to inspect potential issues.
7. Open **Debugging Coach** to investigate coding problems.

## 💻 Requirements

- Visual Studio Code compatible with the extension manifest.
- An open workspace for project analysis.
- Compatible VS Code Language Model access for AI-powered features.

AI functionality depends on your configured provider and permissions.

## 🔒 Privacy

- Project scanning and Codebase X-Ray are designed for local, read-only analysis.
- AI features may send selected code or relevant context to the configured language model provider.
- Avoid sharing confidential source code, passwords or API keys with AI providers unless you understand their data policies.
